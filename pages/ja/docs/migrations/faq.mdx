# よくある質問（FAQ）— メインネットへの移行

## 全般

### Pontus-X メインネットへ移行する目的は何ですか
メインネットへ移行することで、アセットやアプリケーションを、実際の経済的価値を伴う本番環境で稼働させられます。セキュリティも向上し、他のメインネット参加者とやり取りできるようになります。

### メインネットの取引にはどのような費用がかかりますか
テストネットと異なり、メインネットの取引には OASIS ROSE トークンによるガス代が必要です。操作を行う前に、アカウントに十分な残高があることを確認してください。通常のネットワーク状況では、公開（パブリッシュ）にかかる費用は 1 セント未満です。

## 移行の手順

### 移行の準備はどう進めればよいですか
次の手順に従ってください。
1. すべての機能をテストネットで検証する。
2. 本番用ウォレットを用意し、デプロイに十分な OASIS ROSE トークンを確保する。
4. 設定をメインネットのアドレスに更新する。
5. 管理された手順で移行を実行する。

### 移行中に問題が起きた場合はどうすればよいですか
問題が発生した場合は、サポートチームに連絡するか、1 対 1 のトラブルシューティングセッションを依頼してください。

### 移行後にテストネットへ戻せますか
メインネットのアセットは、テストネットのアセットと並行して存在します。メインネットでのアセット提供をやめたい場合は、テストネットと同じ手順で提供を終了できます。

## セキュリティとアカウント管理

### 移行後にアセットの安全を確保するにはどうすればよいですか
- アセット管理にはマルチシグウォレットを使用する。
- 秘密鍵はハードウェアウォレットに安全に保管する。
- 不審な活動を検知するリアルタイム監視を有効にする。
- 秘密鍵の安全なオフラインバックアップを作成する。

### 共有された鍵を移行に使っても安全ですか
いいえ。サービス提供物、アイデンティティ、関連する資金に対する主権を保つため、必ず自分が管理する秘密のアドレスへアセットを移してください。

## 移行後

### 移行が成功したかどうかはどう確認しますか
次を確認してください。
- ブロックエクスプローラーでスマートコントラクトのデプロイを確認する。
- ポータルまたは Nautilus を通じてアセットの取引を試し、正しく実行されることを確認する。
- API 連携とメインネット上の機能を検証する。

### さらに支援が必要な場合はどこに連絡すればよいですか
追加のサポートが必要な場合は、次の方法があります。
- Pontus-X の開発者コミュニティに投稿する。
- サポートチームに連絡し、1 対 1 の相談を依頼する。
