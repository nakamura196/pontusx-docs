開発者の方にも業務担当者の方にも、Web3 技術に詳しくない場合でも円滑かつ安全に移行できるよう構成しています。

## 2. メインネット取引のためのアドレスへの入金

アセットを公開する前に、組織のウォレットに OASIS ROSE トークンを入金する必要があります。

トークン移転の手順
	1.	割り当てられたアカウントにログインします。
	2.	OASIS ROSE トークンを、自分が管理するアドレスへ移します。
	3.	公開や取引の操作には、すべて組織のアドレスを使用します。

**セキュリティ上の注意**：共有アカウントは侵害されているものとみなしてください。利用前に必ず、組織のアカウントへ資金を移してください。

## 3. PTX トークン — 用途と入手方法

### PTX トークンとは
- PTX トークンは、MVP 期間中にエコシステム内でアセットの価格を記録するために使われます。
- 交換の記録用トークンとして機能し、のちの請求処理にも用いられます。
- 記録用トークンは、電子マネーが利用可能になり次第、置き換えられる予定です。

### PTX トークンの入手方法
- 新しいウォレットアドレスを deltaDAO に送ると、PTX を受け取れます。
- （長期的な価格の安定性を確保するため、PTX はのちにステーブルコインへ置き換えられる予定です。）

### PTX の使われ方
- Nautilus 利用者の場合：アセット設定で PTX を価格トークンとして手動で指定する必要があります。
- MVP ポータル利用者の場合：アセット公開時に、ポータルが PTX を自動的に扱います。

## 4. メインネットへのアセット公開

メインネットにアセットを公開する方法は 2 つあります。

### 方法 1：Nautilus（開発者向け）
- プログラムによるアセット管理を好む開発者に推奨されます。
- カスタム設定、自動化、既存システムとの統合に対応します。

**参考資料**
- [Nautilus の GitHub サンプル](https://github.com/deltaDAO/nautilus-examples)
- [メインネット用の設定ファイル](https://github.com/deltaDAO/nautilus-examples/blob/main/config.ts)
- [Nautilus のセットアップガイドとドキュメント](https://nautilus.delta-dao.com/docs/getting-started)

### 方法 2：MVP ポータル（非開発者向け）
- アセットの公開と管理を行える、使いやすい Web ベースの手段です。
- ノーコードで進めたい企業・利用者に推奨されます。

**参考資料**：
- [MVP ポータル](https://portal.main.pontus-x.eu/)
- [MVP ポータルの GitHub](https://github.com/deltaDAO/mvp-portal)

## 5. 確認とトラブルシューティング

### 最終確認の手順

アセットを公開したら、次を確認してください。
- Nautilus または MVP ポータル上で、アセットが正しく表示されていること。
- 他の利用者がエラーなくアセットにアクセスし、利用できること。

### よくある問題と対処

- アセットが表示されない：正しいチェーン ID と設定が使われているか確認してください。
- トランザクションが失敗する：ガス代に足りるだけの OASIS ROSE トークンがあるか確認してください。
- アセットを利用できない：PTX トークンの残高とコントラクトの設定を確認してください。

困ったときは
- サポートコミュニティに参加して質問し、助言を得られます。
- 優先的な技術支援が必要な場合は、エンタープライズサポートにお問い合わせください。
