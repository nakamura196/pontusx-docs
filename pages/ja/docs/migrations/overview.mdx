# 概要：Pontus-X の移行ガイド

テストネットからメインネットへの移行は、本番ネットワーク上にアセットを展開するうえで重要な工程です。本章では、円滑に移行するためのベストプラクティス、確認手順、よくある質問を詳しく解説します。

## 移行が重要な理由

テストネットからメインネットへ移行することで、アプリケーションとアセットが実環境で完全に機能するようになります。安全で分散的な環境のもと、実際の取引や他の利用者とのやり取りが可能になります。

**移行による主な利点**
- 収益化：実際の取引と経済的インセンティブが可能になります。
- 信頼性：実際の経済的価値を持つ安定した環境にアセットを展開できます。
- 相互運用性：他のメインネット参加者やサービスと連携できます。

問題が起きた場合は、FAQ を参照するか、Pontus-X コミュニティにお問い合わせください。円滑な移行をサポートします。
