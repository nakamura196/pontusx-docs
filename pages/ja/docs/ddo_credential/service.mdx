# サービス

| 属性 | 型 | 説明 | 必須 |
| ----------------------- | ----------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| `id`                    | `string`                                                                | 一意の ID。 | :white_check_mark:                                               |
| `type`                  | `string` の列挙                                                          | サービスの種別。`access` または `compute`。 | :white_check_mark:                                               |
| name                    | `string`                                                                | サービスの分かりやすい名称。 | :white_check_mark:                                               |
| displayName             | [`language value オブジェクト`](/ja/docs/ddo_credential/language_i18n)                | アプリケーション上で人が読みやすいよう表示する、サービスの説明的な名称。 |                                                                  |
| `description`           | [`language value オブジェクト`](/ja/docs/ddo_credential/language_i18n)                | サービスの説明。 |                                                                  |
| `datatokenAddress`      | `string`                                                                | サービス固有トークンのスマートコントラクトアドレス。 | :white_check_mark:                                               |
| `serviceEndpoint`       | `string`（URL）                                                         | アクセスコントローラー（Provider）の URL。 | :white_check_mark:                                               |
| `files`                 | `string`（暗号化された [`files オブジェクト`](/ja/docs/ddo_credential/files_object)） | ファイルへのアクセス制御情報を暗号化したもの（アクセスコントローラー／Provider によって暗号化されます）。 | :white_check_mark:                                               |
| `timeout`               | `number`                                                                | 利用開始後、サービスをどれだけの期間使えるかを表します。`0` は無期限を意味します。単位は秒。 | :white_check_mark:                                               |
| `compute`               | [`compute_object`](/ja/docs/ddo_credential/compute_object)                      | サービスの `type` が `compute` の場合、計算処理に関するプライバシー設定とリソース情報を保持します。 | :ballot_box_with_check:（`type` が `compute` のサービスでは必須） |
| `consumerParameters`    | [`consumerParameters`](/ja/docs/ddo_credential/service_consumer_parameters)     | アセットを利用する前に必要となる、利用者からの入力を定義するオブジェクト。 |                                                                  |
| `additionalInformation` | Object                                                                  | 追加情報を格納します。公開者が自由に定義できます。 |                                                                  |
| `state`                 | `number` の列挙 [`state`](/ja/docs/ddo_credential/lifecycle_states)               |                                                                                                                                              | :white_check_mark:                                               |
| `credentials`           | [`credentials`](/ja/docs/ddo_credential/credentials)                            | アクセス制御用のクレデンシャル。 | :white_check_mark:                                               |
| `dataSchema`            | [`remoteObject`](/ja/docs/ddo_credential/remote_object)                         | データサービスのスキーマを定義するリモート文書。 | （`dataset` 型のアセットのみ）                                     |
| `inputSchema`           | [`remoteObject`](/ja/docs/ddo_credential/remote_object)                         | 特定のアルゴリズムが期待する入力データのスキーマを定義するリモート文書。 | （`algorithm` 型のアセットのみ）                                   |
| `outputSchema`          | [`remoteObject`](/ja/docs/ddo_credential/remote_object)                         | アルゴリズムの出力のスキーマを定義するリモート文書。 | （`algorithm` 型のアセットのみ）                                   |
