# ODRL オブジェクト

ODRL（Open Digital Rights Language）はポリシー記述言語であり、コンテンツやサービスの利用に関する記述を表現するための、柔軟で相互運用可能な情報モデル、語彙、エンコード方式を提供します。

Ocean Enterprise の技術スタックは ODRL ポリシーの定義を可能にしますが、それを強制する技術的手段までは提供しません。アクセス制御は `credentials` オブジェクトによって実装されます。

ODRL の詳細については次を参照してください。

- **ODRL 情報モデル：** https://www.w3.org/TR/odrl-model/

- **ODRL 語彙と表現：** https://www.w3.org/TR/odrl-vocab/

- **実装のベストプラクティス：** https://w3c.github.io/odrl/bp/
