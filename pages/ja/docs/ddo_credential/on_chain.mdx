# オンチェーンメタデータ — OE サービスクレデンシャルの記録

カタログ項目の特定のメタデータは、データの信頼性と完全性を確保するためにブロックチェーン上に保存（アンカリング）されます。オンチェーンの保存内容は不変であり、削除できません。そのため、ブロックチェーンに保存してよいのは限られたメタデータのみです。

さらなる保護層として、データスペースにおけるプライバシーとアクセス制御を強化するために、データは暗号化もされます。

## オンチェーンの remote オブジェクト

:::danger
以下で定義する remote データオブジェクト以外のデータを、オンチェーンに保存してはいけません。オンチェーン・オフチェーンいずれのデータも、常に暗号化されなければ **なりません**。
:::

:::info
その他のメタデータは、IPFS などのウェブストレージを用いてオフチェーンに保存しなければ **なりません**。これは GDPR その他のデータ保護規制（たとえば GDPR の消去権）に準拠するうえで重要です。

`fileHash` がオフチェーンデータ（OE 検証可能プレゼンテーション）の完全性を担保します。これにより、規制対象のデータ（個人を特定できる情報など）をオンチェーンに保存する必要がなくなります。
:::

暗号化前の remote オブジェクトの例：

```ts
export const remoteDDOTypeURL = {
  remote: {
    type: 'url',
    url: 'path.to/encrypted/oe-verifiable-presentation',
    method: 'GET'
    fileHash: "xyz"
    encryptedBy: '16Uiu2HAmN211yBiE6dF5xu8GFXV1jqZQzK5MbzBuQDspfa6qNgXF',
    encryptedMethod: 'ECIES'
  }
}

export const remoteDDOTypeIPFS = {
  remote: {
    type: 'ipfs',
    hash: 'QmaD5S7TakPs3a4fijatbfqhmhhrEbCvbqGTTAp7VrZ91T',
    fileHash: "xyz"
    encryptedBy: '16Uiu2HAmN211yBiE6dF5xu8GFXV1jqZQzK5MbzBuQDspfa6qNgXF',
    encryptedMethod: 'ECIES'
  }
}
```

| 属性 | 型 | 説明 | 必須 |
| ----------------- | ------------------------- | ---------------------------------------------------- | ---------------------------------------------- |
| `type`            | `sring`（`ipfs`、`url`）  | リモート格納先の種別を指定します。<br/>（訳注: 型名の `sring` は原文のままです。`string` の誤記と思われます。） | :white_check_mark:                             |
| `hash`            | `string`                  | IPFS リソースの CID。 | :ballot_box_with_check:（`ipfs` 型のみ） |
| `method`          | `string`（`GET`、`POST`）   | HTTP メソッド。 | :ballot_box_with_check:（`url` 型のみ）  |
| `url`             | `string`                  | 暗号化された OE 検証可能プレゼンテーションを指す URL。 | :ballot_box_with_check:（`url` 型のみ）  |
| `fileHash`        | `string`                  | データオブジェクトの sha256 ハッシュ。 | :white_check_mark:                             |
| `encryptedBy`     | `string`                  | ocean-node の ID（秘密鍵から導出）。 | :white_check_mark:                             |
| `encryptedMethod` | `string`（`ecies`、`aes`） | 使用した暗号化方式。 | :white_check_mark:                             |
