# 言語と基底方向 (i18n)

W3C の標準に従います: https://w3c.github.io/vc-data-model/#language-and-base-direction

https://www.w3.org/TR/string-meta/

| 属性 | 型 | 説明 | 必須 |
| ------------ | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------ |
| `@value`     | `string` | 特定の 1 言語で書かれたテキスト。 | :white_check_mark: |
| `@language`  | `string` | [[BCP47](https://w3c.github.io/vc-data-model/#bib-bcp47)] で定義される `Language-Tag`。 | :white_check_mark: |
| `@direction` | `string` | [[JSON-LD11](https://w3c.github.io/vc-data-model/#bib-json-ld11)] の `@direction` プロパティで定義される[基底方向](https://www.w3.org/TR/i18n-glossary/#dfn-base-direction)の文字列を値とする `@direction` プロパティを含めても _よい_（MAY）。例：`rtl` |                    |

単一の訳：

```json
"title": {
  "@value": "HTML و CSS: تصميم و إنشاء مواقع الويب",
  "@language": "ar",
  "@direction": "rtl"
}
```

複数の訳：

```json
"title": [
  {
    "@value": "HTML and CSS: Designing and Creating Websites",
    "@language": "en"
  },
  {
    "@value": "HTML و CSS: تصميم و إنشاء مواقع الويب",
    "@language": "ar",
    "@direction": "rtl"
  }
]
```
