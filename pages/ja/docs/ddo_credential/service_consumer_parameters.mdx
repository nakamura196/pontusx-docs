# サービスの consumerParameters

サービスの [`consumerParameters`](/ja/docs/ddo_credential/consumer_parameters) は、利用者がサービスを利用する際に提供しなければならない、任意または必須のパラメータを指定するために用います。`GET` リクエストの URL にクエリ文字列を付加したり、`POST` のヘッダーに追加のフィールドを加えたりできます。

ダウンロードや Compute-to-Data のジョブ実行の前に、アセット側が追加の入力データを必要とする場合があります。

**例：**

- 公開者は、購入者がダウンロードする前にサンプリング間隔を知る必要があります。データセットの URL が https://example.com/mydata だとします。
- 公開者は sampling というフィールドを定義し、購入者に値の入力を求めます。このパラメータは、公開されたデータセットの URL にクエリパラメータとして付加されます：https://example.com/mydata?sampling=10
