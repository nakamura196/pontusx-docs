# Compute オブジェクト

compute 型のサービスでは必須です。

| 属性 | 型 | 説明 | 必須 |
| ------------------------------------- | -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------ |
| `allowRawAlgorithm`                   | `boolean`                                                            | `true` の場合、渡された任意の生テキストの実行が許可されます。アルゴリズムをドラッグ＆ドロップで扱うユースケースでは便利ですが、悪意ある入力によるデータ流出のリスクが高まります。どの実装でも既定値は `false` とすべきです。 | :white_check_mark: |
| `allowNetworkAccess`                  | `boolean`                                                            | `true` の場合、アルゴリズムのジョブがネットワークにアクセスできます。 | :white_check_mark: |
| `publisherTrustedAlgorithmPublishers` | `string` の配列 | 未定義の場合、公開されたすべてのアルゴリズムが許可されます。空配列の場合は、いずれのアルゴリズムも許可されません。空でない場合は、指定した公開者が公開したアルゴリズムが許可されます。 | :white_check_mark: |
| `publisherTrustedAlgorithms`          | [`publisherTrustedAlgorithms`](#publishertrustedalgorithms) の配列 | 未定義の場合、公開されたすべてのアルゴリズムが許可されます。空配列の場合は、いずれのアルゴリズムも許可されません。それ以外の場合は、配列で定義されたアルゴリズムのみが許可されます（下記参照）。 | :white_check_mark: |

## publisherTrustedAlgorithms

| 属性 | 型 | 説明 | 必須 |
| -------------------------- | -------- | ------------------------------------------------------------------ | ------------------ |
| `did`                      | `string` | 公開者が信頼するアルゴリズムの DID。 | :white_check_mark: |
| `serviceId`                | `string` | 公開者が信頼するアルゴリズムのサービス ID。 | :white_check_mark: |
| `filesChecksum`            | `string` | アルゴリズムのファイルのハッシュ（`string` として）。 | :white_check_mark: |
| `containerSectionChecksum` | `string` | アルゴリズムのイメージ情報のハッシュ（`string` として）。 | :white_check_mark: |
