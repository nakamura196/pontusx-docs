# remoteObject

| 属性 | 型 | 説明 | 必須 |
| ----------------------- | ---------------------------------------- | ------------------------------------------------------------------------ | ------------------ |
| `name`                  | `string`                                 | 内容を表す名称。 | :white_check_mark: |
| `displayName`           | [`language value オブジェクト`](/ja/docs/ddo_credential/language_i18n)                  | アプリケーション上で人が読みやすいよう表示する、ファイルの説明的な名称。 |                    |
| `description`           | [`language value オブジェクト`](/ja/docs/ddo_credential/language_i18n)                  | ファイルの説明。 |                    |
| `fileType`              | `string`                                 | リモートオブジェクトの MIME タイプ。例：`application/pdf` | :white_check_mark: |
| `sha256`                | `string`                                 | リモートオブジェクトの `sha256` ハッシュ。 | :white_check_mark: |
| `mirrors`               | [`remoteSource`](#remotesource) の配列 | ソースの `type` として `url` と `ipfs` を含められます。配列を空にすることはできません。 | :white_check_mark: |
| `additionalInformation` | `Object`                                 | 追加情報を格納します。公開者が自由に定義できます。 |                    |

## remoteSource

### 型 `url`

| 属性 | 型 | 説明 | 必須 |
| --------- | -------- | ------------------------------------- | ------------------ |
| `type`    | `string` | 値は `url`。 | :white_check_mark: |
| `url`     | `string` | リモートオブジェクトの URL。 | :white_check_mark: |
| `method`  | `string` | HTTP メソッド（例：`GET`、`POST`）。 | :white_check_mark: |
| `headers` | `string` | 追加の HTTP ヘッダー。 |                    |

**例：**

```json
{
    "type": "url",
    "url": "https://your-files.com/file1.json",
    "method": "GET",
    "headers": {
      "Custom-Header": "custom-value-if-needed"
    }
}
```



### 型 `ipfs`

| 属性 | 型 | 説明 | 必須 |
| --------- | -------- | ------------------------------------------------------------ | ------------------ |
| `type`    | `string` | 値は `ipfs`。 | :white_check_mark: |
| `ipfsCID` | `string` | *コンテンツ識別子*（[CID](https://docs.ipfs.tech/concepts/content-addressing/#what-is-a-cid)）は、IPFS 上の資料を指し示すためのラベルです。 | :white_check_mark: |



例：

```json
{
  "type": "ipfs",
  "ipfsCID": "QmRA3NWM82ZGynMbYzAgYTSXCVM14Wx1RZ8fKP42G6gjgj"
}
```
