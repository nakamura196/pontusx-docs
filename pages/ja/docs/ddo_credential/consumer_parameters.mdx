# consumerParameters

`consumerParameters` はオブジェクトの配列です。各オブジェクトが 1 つのフィールドを定義し、次の構造を持ちます。

| 属性 | 型 | 説明 | 必須 |
| ------------- | -------------------------------- | -------------------------------------------------------------------------- | ----------------------------------------------------- |
| `name`        | `string`                         | パラメータ名（HTTP のパラメータ、またはアルゴリズムへ渡すキーとして送られます）。 | :white_check_mark:                                    |
| `type`        | `string`                         | フィールドの型（text、number、boolean、select）。 | :white_check_mark:                                    |
| `label`       | `string`                         | 表示されるフィールドのラベル。 | :white_check_mark:                                    |
| `required`    | `boolean`                        | このフィールドへの利用者の入力が必須かどうか。 | :white_check_mark:                                    |
| `description` | `string`                         | フィールドの説明。 | :white_check_mark:                                    |
| `default`     | `string`、`number`、`boolean` のいずれか | フィールドの既定値。select 型の場合は、既定の選択肢を表す `string` のキー。 | :white_check_mark:                                    |
| `options`     | `option` の配列                | select 型の場合の選択肢の一覧。 | :ballot_box_with_check:（`select` 型では必須） |

各 `option` は、キーが選択肢名、値が選択肢の値である単一のキーと値の組を持つ `object` です。

**例：**

```json
[
  {
    "name": "hometown",
    "type": "text",
    "label": "Hometown",
    "required": true,
    "description": "What is your hometown?",
    "default": "Nowhere"
  },
  {
    "name": "age",
    "type": "number",
    "label": "Age",
    "required": false,
    "description": "Please fill your age",
    "default": 0
  },
  {
    "name": "developer",
    "type": "boolean",
    "label": "Developer",
    "required": false,
    "description": "Are you a developer?",
    "default": false
  },
  {
    "name": "languagePreference",
    "type": "select",
    "label": "Language",
    "required": false,
    "description": "Do you like NodeJs or Python",
    "default": "nodejs",
    "options": [
      {
        "nodejs": "I love NodeJs"
      },
      {
        "python": "I love Python"
      }
    ]
  }
]
```
