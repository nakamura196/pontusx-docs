# licenseObject

| 属性 | 型 | 説明 | 必須 |
| ------------------ | ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------ |
| `name`             | `string`                                               | ライセンスを表す簡潔な名称（例：`Apache License 2.0`、`MIT`）。 | :white_check_mark: |
| `ODRL`             | [`ODRL オブジェクト`](/ja/docs/ddo_credential/odrl_object)（JSON-LD） | ODRL は、何かが許可されているか、禁止されているか、義務づけられているかを、必要に応じて制約付きで表現するための、構造化された機械可読な言語です。このオブジェクトで定義されるポリシーはアクセス制御には用いられませんが、利用者がデータをどのように使ってよいかを伝えるために利用できます。 |                    |
| `licenseDocuments` | [`remoteObject`](/ja/docs/ddo_credential/remote_object) の配列 | ライセンスに関連する任意のファイル。 |                    |
