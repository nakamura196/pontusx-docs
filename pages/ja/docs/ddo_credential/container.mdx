# コンテナ

| 属性 | 型 | 説明 | 必須 |
| ------------ | -------- | --------------------------------------------------------------------------------------------------------------------------------------- | ------------------ |
| `image`      | `string` | アルゴリズムを実行する Docker イメージ名。 | :white_check_mark: |
| `tag`        | `string` | 使用する Docker イメージのタグ。 | :white_check_mark: |
| `entrypoint` | `string` | Docker のエントリーポイント。`$ALGO` はマクロで、アルゴリズムのコードがどこにダウンロードされるかに応じて、計算ジョブ内で置き換えられます。 | :white_check_mark: |

**例：**

Node.js v18 を基盤として、JavaScript／Node.js で書かれたアルゴリズムを実行する場合：

```json
{
  "algorithm": {
    "container": {
      "entrypoint": "node $ALGO",
      "image": "node",
      "tag": "18"
    }
  }
}
```
