# クレデンシャル（アクセス制御）

既定では、利用者は datatoken を 1 つ保有していればリソースにアクセスできます。*クレデンシャル* を使うと、公開者は任意でより細かい権限を指定できます。

たとえば医療データのユースケースでは、資格を持つ EU の研究者のみが法的に当該データセットへアクセスできる、という場合があります。Ocean はこれを次のように実現します。利用者は datatoken を 1 つ保有し、*かつ* 指定された `"allow"` クレデンシャルのいずれかを満たす場合にのみ、リソースにアクセスできます。

**アドレスに基づく例：** 

```json
{
  "credentials": {
    "allow": [
      {
        "type": "address",
        "values": ["0x123", "0x456"]
      }
    ],
    "deny": [
      {
        "type": "address",
        "values": ["0x2222", "0x333"]
      }
    ]
  }
}
```

**ポリシーに基づく例**

次の例では、特定のクレデンシャル属性を検査できます（ポリシーが検証コンポーネント側で定義されていることを前提とします）。

https://docs.oss.walt.id/verifier/api/vc-oid4vc#example-verification-request-3-applying-policies-to-specific-credentials

```json
{
  "credentials": {
    "allow": [
      { "type": "verifiableCredential",
        "requestCredentials": [
        "VerifiableId",
        "ProofOfResidence",
        {
          "credential": "OpenBadgeCredential",
          "policies": [
            "signature",
            {
              "policy": "3.test",
              "args": {
                "type": "object"
              }
            }
          ]
        }
      ]}
    ]
  }
}
```
