# ライフサイクル状態

#### アセットの状態

各アセットは状態を持ち、それは NFT コントラクトによって保持されます。取り得る状態は次のとおりです。

| 状態 | 説明 | Ocean Market で検索可能 | 注文可能 | プロフィールに表示 |
| ----- | ------------------------------ | ---------------------------- | ---------------- | -------------------- |
| `0`   | 有効（Active） | はい | はい | はい |
| `1`   | 提供終了（End-of-life） | はい | いいえ | いいえ |
| `2`   | 他のアセットにより非推奨化 | いいえ | いいえ | いいえ |
| `3`   | 公開者により失効 | いいえ | いいえ | いいえ |
| `4`   | 注文を一時的に停止 | はい | いいえ | はい |
| `5`   | 一覧非掲載（unlisted） | いいえ | はい | はい |

| 状態 | 説明 | マーケットで検索可能 | 注文可能 | プロフィールに表示 |

| `1`   | 提供終了（End-of-life） | はい | いいえ | いいえ |

| `4`   | 注文を一時的に停止 | はい | いいえ | はい |
