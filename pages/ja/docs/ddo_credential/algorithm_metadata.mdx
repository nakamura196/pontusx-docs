# アルゴリズムのメタデータ

| 属性 | 型 | 説明 | 必須 |
| -------------------- | -------------------------------------------------------------- | ------------------------------------------------------------------------------------------ | ------------------ |
| `container`          | [`container`](/ja/docs/ddo_credential/container)                   | Docker コンテナイメージを記述するオブジェクト。 | :white_check_mark: |
| `language`           | `string`                                                       | ソフトウェアの実装に用いた言語。 |                    |
| `version`            | `string`                                                       | ソフトウェアのバージョン。[SemVer](https://semver.org) 表記が望ましい（例：`1.0.0`）。 |                    |
| `consumerParameters` | [`consumerParameters`](/ja/docs/ddo_credential/algorithm_consumer_parameters) | アルゴリズムの実行前に利用者からの入力として必要な項目を定義するオブジェクト。 |                    |
