# W3C 検証可能クレデンシャルと検証可能プレゼンテーション

[W3C Verifiable Credentials](https://www.w3.org/TR/vc-data-model-2.0/) と Verifiable Presentations は、ウェブ上でデジタルクレデンシャルを表現し検証するための標準的な手段を提供します。主な利点は次のとおりです。

1. 信頼と検証：発行者に直接問い合わせることなく、任意の検証者がクレデンシャルの真正性を確認できます。これは暗号学的な証明によって実現されます。

2. 相互運用性：W3C 標準であるため、異なるシステムやプラットフォーム間での相互運用性が確保されます。

3. 柔軟性：Ocean Enterprise のサービスクレデンシャルとあわせて、あらゆる種類の資格や認証を提示できます。これによりデータエコシステム間の相互運用性が確保されます。

4. セキュリティ：クレデンシャルとプレゼンテーションの保護に JOSE（JSON Object Signing and Encryption）を用いることで、改ざんや偽造に対する堅牢なセキュリティが得られます。

検証可能プレゼンテーションとクレデンシャルは [`JOSE`](https://www.w3.org/TR/vc-jose-cose/) によって保護されます。[Securing JSON-LD Verifiable Presentations with JOSE](https://www.w3.org/TR/vc-jose-cose/#securing-vps-with-jose) を参照してください。

つまりクレデンシャルは署名され、JWT 形式でエンコードされます。JWT は、JSON データをコンパクトかつ安全にエンコードするために広く使われている標準です。

クレデンシャルとプレゼンテーションに署名する際、発行者はブロックチェーンアカウントの秘密鍵を用いてデジタル署名を作成します。検証者は発行者の公開鍵を用いて、その署名を検証できます。
