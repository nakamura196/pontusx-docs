# metadata

| 属性 | 型 | 説明 | 必須 |
| ----------------------- | -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------- |
| `created`               | `ISO 日付／時刻文字列`                                         | データセットの内容が作成された日付を ISO 8601 形式で記述します。タイムゾーン指定子を含めることが望ましいです（例：`2000-10-31T01:30:00Z`）。 | :white_check_mark:                                            |
| `updated`               | `ISO 日付／時刻文字列`                                         | データセットの内容が作成された日付を ISO 8601 形式で記述します。タイムゾーン指定子を含めることが望ましいです（例：`2000-10-31T01:30:00Z`）。 | :white_check_mark:                                            |
| `description`           | [`language value オブジェクト`](/ja/docs/ddo_credential/language_i18n)                                        | そのリソースが何であるかの詳細。データセットの場合、データが何を表し、何に使えるのかを説明します。 | :white_check_mark:                                            |
| `copyrightHolder`       | `string`                                                       | 法的な著作権を保有する主体。 |                                                               |
| `name`                  | `string`                                                       | アセットの説明的な名称。 | :white_check_mark:                                            |
| `displayTitle`          | [`language value オブジェクト`](/ja/docs/ddo_credential/language_i18n)                                        | アプリケーション上で人が読みやすいよう表示する、アセットの説明的な名称。 |                                                               |
| `type`                  | `string` の列挙                                                  | アセットの種別。`"dataset"`（CSV ファイルなど）、`"algorithm"`（Python スクリプトなど）を含みます。種別ごとに必要なメタデータ属性の組み合わせが異なります。 | :white_check_mark:                                            |
| `author`                | `string`                                                       | このデータを生成した主体の名称（例：`deltaDAO AG`）。 |                                                               |
| `providedBy`            | `string` の URL（参加者クレデンシャル）                          | このアセットを提供する主体の検証可能クレデンシャル。 | :white_check_mark:                                            |
| `license`               | [`licenseObject`](/ja/docs/ddo_credential/license_object)          | このアセットのすべてのサービスに適用されるライセンス。 |                                                               |
| `links`                 | Object                                                         | URL のタイトル（キー）と URL 文字列（値）の対応。 |                                                               |
| `attachments`          | [`remoteObject`](/ja/docs/ddo_credential/remote_object) の配列                                        | アセットに添付されたリモートファイルの一覧。 |                                                               |
| `tags`                  | `string` の配列                                              | この内容を説明するキーワードやタグの配列。既定では空です。 |                                                               |
| `categories`            | `string` の配列                                              | アセットに紐づくカテゴリの配列。 |                                                               |
| `additionalInformation` | Object                                                         | 追加情報を格納します。公開者が自由に定義できます。 |                                                               |
| `algorithm`             | [`アルゴリズムのメタデータ`](/ja/docs/ddo_credential/algorithm_metadata) | `algorithm` 型のアセットに関する情報。 | :ballot_box_with_check:（アセット種別が `algorithm` の場合は必須） |
