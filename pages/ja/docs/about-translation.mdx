## 改変点

原典に対して、翻訳版では次の変更を加えています。

**訳文の追加**

- `pages/docs/` 配下の本文を日本語に翻訳し、`pages/ja/docs/` として追加（英語版のページはそのまま残しています）
- ドキュメント内部のリンクを日本語版のパスへ張り替え
- サイドバーの日本語版（`sidebar.ja.ts`）とトップナビゲーションの言語切替を追加

**原典の不具合に対する翻訳版側の対応**

- 存在しないページを指していた内部リンク 3 件を、意図された内容に最も近いページへ付け替え（`getting-started/quick-start` と `getting-started/introduction` は「オンボーディングガイド」へ、`Basic Concepts/data_service_offerings` は「データサービス提供物」へ）
- ビルド出力に存在しないパスを指していた `.mdx` 拡張子付きの内部リンク 3 件から、拡張子を除去
- 原文の記述が途中で切れている箇所や、明らかな誤記をそのまま残した箇所には、訳注を添えています

**公開のためのビルド設定**

- GitHub Pages 向けのビルド設定（`BASE_PATH`）と公開用ワークフローを追加
- Node のバージョンを 22 に固定（`.nvmrc`）。Node 25 では依存パッケージの不具合でビルドが失敗するため
- `basePath` を指定するとページのプリレンダ結果が空になる、画像などのパスに接頭辞が付かない、といった Vocs 側の不具合を回避する処理を追加（`scripts/patch-vocs.mjs`、`scripts/basePathAssets.ts`）
- 上流サイトのアクセス解析タグは、フォーク版のビルドでは読み込まないよう変更

## 訳語の方針

- 製品名・プロトコル名・コンポーネント名（Pontus-X, Gaia-X, Ocean Enterprise, Aquarius, Nautilus, Compute-to-Data など）は原語のまま表記します
- API のフィールド名・型名・コード中の識別子は翻訳せず、説明文のみを日本語にします
- 定訳のない概念語は、初出時に「データ主権（data sovereignty）」のように原語を併記します
