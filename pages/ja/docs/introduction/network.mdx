# Pontus-X ネットワークとは

Pontus-X ネットワーク（Pontus-X テストネットとも呼ばれます）は、コミュニティ主導の汎欧州ネットワークであり、Gaia-X で初めて完全に分散化されたデータスペースである Pontus-X エコシステムのための、中立な分散型物理インフラ（DePIN）およびソフトウェアインフラです。誰の所有物でもなく誰にでも開かれており、Gaia-X Association for Data and Cloud（AISBL）のトラストフレームワークに賛同する Gaia-X コミュニティメンバーによって全面的に運用・統治されています。

![Pontus-X Network](/images/network-pontus-c.jpg)

Pontus-X ネットワークは、Oasis Protocol を用い Oasis ParaTime を活用して構築された、カスタマイズ可能なブロックチェーンです。拡張を続けるソフトウェアスタックにより、コンソーシアム・中小企業・公的機関それぞれのニーズやユースケースに合わせた、業種特化型のデータスペースとエコシステムを構築できます。今後は他のネットワークやソフトウェアスタックも加わり、機能を拡張してエコシステム固有のニーズに対応していきます。

デジタル取引のための中立・オープン・分散的かつ安全なインフラを提供することで、本ネットワークは、企業や機関が自らのデータとその利用方法をより強く制御できるようにし、同時に Gaia-X トラストフレームワークへの準拠も確保します。これは Pontus-X および Gaia-X のエコシステム内での信頼と相互運用性を育て、新たなデータサイロを生むことなく、複数の当事者が分散的かつ自律的に利用できるデータスペースを可能にします。
