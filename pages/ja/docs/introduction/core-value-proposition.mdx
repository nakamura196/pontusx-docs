# Pontus-X の中核となる価値提案

## はじめに
デジタル経済とその成長は、組織や分野をまたいでデータ・ソフトウェア・AI サービスを安全かつ効率的に共有し活用できるかに、ますます左右されるようになっています。[Pontus-X](https://www.pontus-x.eu/) のような産業データスペースは、長年の課題であるデータサイロ、相互運用性、主権に対処する変革的なパラダイムとして登場しました。標準化された信頼ベースのデータ交換の枠組みを提供することで、Pontus-X は、組織が自らのデータ資産とデジタルサービスを管理し続けたまま協働できるようにします。

### デジタル単一市場の創出
Pontus-X は、異なるデータスペース、業種、組織、国、そしてデータスペース技術フレームワークをまたいだデジタル単一市場を生み出します。[FIWARE Orion Context Broker](https://fiware-orion.readthedocs.io/en/master/)、[Eclipse Dataspace Components (EDC)](https://projects.eclipse.org/projects/technology.edc)、[Prometheus-X (PMX)](https://prometheus-x.org/) をはじめ、さまざまなデータプラットフォームやデータスペースフレームワークと接続できます。Pontus-X と、その基盤となるデータスペース向け [Ocean Enterprise Protocol](https://www.oceanenterprise.io/) は、孤立したデータスペースの実装どうしをつなぐ結合組織であり、抽象化レイヤーとして機能します。

### デジタルサービスのマーケットプレイスと流通基盤

Pontus-X は、非公開データやデジタルサービスを売買したい当事者間の購買取引を可能にします。参加者は自らのデータ製品やデジタルサービス製品（AI、ソフトウェア）を作り出せる一方、Compute-to-Data（CtD）とアクセス制御によって知的財産とプライバシーを堅牢に保護できるため、そこに価値が生まれます。さらに Pontus-X は、オープンデータの共有と利用を可能にすることで、公益のためのデータ・デジタルサービスの共有も支えます。

### 経済的な持続可能性を前提とした設計
Pontus-X はエコシステムの持続可能性と成長を確かなものにするため、複数の経済モデルを採用し、各参加者に明確で透明性のあるビジネスモデルを提供します。[基本概念](/ja/docs/getting-started/core-concepts) を参照してください。

### 相互運用性と信頼
Pontus-X は、組織や国境をまたいだデータ・ソフトウェア・インフラの共有を、円滑かつ安全に行えるようにします。Ocean Enterprise Protocol を活用することで相互運用性を確保し、参加者間の信頼を築きます。これにより企業や公的機関は、情報漏えいや不正利用を恐れることなくデジタルサービスを共有できます。

### 技術的なデータ主権
最高水準のデータ保護とプライバシーの基準を守ることで、組織は自らのデータとデジタルサービスを完全に管理し続けられます。[基本概念](/ja/docs/getting-started/core-concepts) を参照してください。

### 効率性
Pontus-X と [Ocean Enterprise](https://www.oceanenterprise.io/) は、効率性とコスト最小化を念頭に構築されています。各サービスは最小限のリソース割り当てで導入・維持・利用でき、総所有コスト（TCO）やその他の間接費用を抑えられます。

### 経済的効果と生産性向上の解放
最先端技術の継続的な開発と統合を後押しし、生産性を通じてデジタルトランスフォーメーションと経済成長を牽引します。

Pontus-X は、新たなビジネスモデルを可能にし、生産性を高め、イノベーションを加速することで、大きな経済的価値を解き放ちます。オープンデータのエコシステムは、分野をまたいだデータ駆動の知見とサービスを促進することで、世界全体で 3 兆ドルを超える追加的価値を生むと推計されています。データサイロを減らし、フェデレーテッドなデータアクセスを可能にすることで、Pontus-X は AI・機械学習の開発を加速し、データ主権を損なうことなく分散したデータセットから実用的な知見を引き出せるようにします。

### 柔軟でインフラに依存しない設計
[モジュール化された Pontus-X のコンポーネント](/ja/docs/technical-architecture/architecture-overview) は、パブリッククラウドからエッジ、IoT 環境まで、ほぼあらゆるインフラ上に配置できます。これにより最大限の柔軟性が得られ、特定のクラウドやインフラサービスへのロックインを防げます。

### オープンソースソフトウェア
[Pontus-X のリファレンスエコシステム](https://portal.pontus-x.eu/) は、中核部分が自由なオープンソースソフトウェア（FOSS）で構築されており、透明で、誰でも入手でき、検証・監査が可能です。これにより参加者は完全な制御権を持ち、参加への門戸も開かれます。

### 透明性
デジタルエコシステム上のあらゆる取引とガバナンスのプロセスにおいて、開放性と説明責任を推進します。

### 協働
参加者が知識・リソース・サービスを自由に共有し、共通の目標を達成できる協調的な環境を育てます。同時に、必要な範囲で知的財産（IP）の管理権は保たれます。

### セキュリティ
データを保護し、エコシステム全体で安全なデジタル相互作用を確保する堅牢な仕組みを実装します。

### 持続可能性
効率的で分散的な技術を通じて、環境的にも経済的にも持続可能な事業慣行を支えます。

### コンプライアンス
欧州の規制と [Gaia-X トラストフレームワーク](https://docs.gaia-x.eu/) に従い、国際的な法的・倫理的基準を満たします。Pontus-X は、ビジネスユースケースをすぐに始められるようカスタマイズ可能な契約テンプレートを提供します。欧州データ法（DA）、欧州データガバナンス法（DGA）、欧州 AI 法（AIA）などの要件充足を支援します。

### プライバシー
Pontus-X の根幹をなす要素であり、参加者のデータの完全性と機密性を守ります。[基本概念](/ja/docs/getting-started/core-concepts) を参照してください。

### 共同運用
Pontus-X は分散モデルで運用され、制御と運用が複数のノードと参加者に分散されています。この方式により自由な競争が確保され、中央集権的なプラットフォーム事業者ではなく参加者自身が所有し制御するエコシステムが実現します。[基本概念](/ja/docs/getting-started/core-concepts) を参照してください。

### データスペースをまたいだ協働
Pontus-X は、異なるデータスペースをまたいだ円滑な協働を可能にします。[基本概念](/ja/docs/getting-started/core-concepts) を参照してください。

## DSSC ビルディングブロックの上に築く

Pontus-X と [Ocean Enterprise](https://www.oceanenterprise.io/) のオープンソースデータスペースフレームワークは、Data Space Support Centre（DSSC）の技術ビルディングブロック、および [Data Spaces Toolbox](https://toolbox.dssc.eu/) の一部です。Toolbox は、スケーラブルなデータスペースのエコシステムを構築するための主要コンポーネント実装を精査・厳選したカタログです。

## Eurostack と欧州によるガバナンス

Pontus-X と、その基盤である [Ocean Enterprise](https://www.oceanenterprise.io/) のオープンソースデータスペースフレームワークおよびプロトコルは、欧州の機関とステークホルダーによって民主的に統治されています。
