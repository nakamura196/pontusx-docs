# Pontus-X ポータル

Pontus-X のポータルは、カタログを閲覧し、特定のサービス提供物を検索する手段を利用者に提供します。さらにポータルは、サービスの公開・注文・利用を簡単に行う機能も備えています。1 つのポータルは複数のネットワークに同時に接続でき、基盤となるインフラ（Pontus-X ネットワーク）が共通であることから、他のポータルとも相互運用できるよう設計されています。

ポータルは設定によってカスタマイズでき、選んだサービスだけを表示することも可能です。Pontus-X のリファレンスポータルは https://www.pontus-x.eu/ から利用できます。
