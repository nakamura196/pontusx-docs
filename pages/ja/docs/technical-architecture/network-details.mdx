# ネットワーク詳細

このページには、Pontus-X テストネットおよび開発ネットに接続するために必要な設定情報、コントラクトアドレス、ミドルウェアのエンドポイントをまとめています。

## MetaMask 用のパラメータ

Pontus-X のテストネットおよび開発ネットを MetaMask ウォレットに追加する際は、以下のパラメータを使用してください。

### テストネット

- ネットワーク名: Pontus-X Testnet
- RPC URL: https://rpc.test.pontus-x.eu/
- チェーン ID: 32457
- 通貨シンボル: EURAU（手数料用）
- ブロックエクスプローラー URL: [https://explorer.pontus-x.eu/pontusx/test](https://explorer.pontus-x.eu/pontusx/test)

### 開発ネット

- ネットワーク名: Pontus-X Devnet
- RPC URL: https://rpc.dev.pontus-x.eu/
- チェーン ID: 32456
- 通貨シンボル: EURAU（手数料用）
- ブロックエクスプローラー URL: [https://explorer.pontus-x.eu/pontusx/dev](https://explorer.pontus-x.eu/pontusx/dev)

:::info
MetaMask を使わずに Pontus-X の開発ネット・テストネットを利用することもできます。[ウォレットの設定](/ja/docs/getting-started/wallet-setup) の章を参照してください。
:::

:::info
独自の RPC ノードやエクスプローラーを運用し、それらを代わりに利用することもできます。
:::

## 決済用 ERC20 トークンのスマートコントラクト

手数料用トークンは、ネットワークを追加した時点でウォレットに自動で追加されます。決済用トークンは、ウォレットの残高として表示するために手動でインポートする必要があります。「トークンをインポート」から、以下のスマートコントラクトアドレスを指定してください。

:::info
**注意：** [EURAU](https://allunity.com/) はネットワーク手数料用トークンとしても使われますが、ERC-20 の EURAU トークンとは同一ではありません。かつて使われていた [EUROe](https://www.euroe.com/) トークンは非推奨です。
:::

## ノード・バリデータへの問い合わせ

以下の curl コマンドで公開 RPC ノードに直接問い合わせ、状態の確認やブロックデータの取得ができます。

### 最新ブロックを取得する

```bash
curl -X POST -H "Content-Type: application/json" --data '{"jsonrpc":"2.0","method":"eth_getBlockByNumber","params":["latest", false],"id":1}' https://rpc.test.pontus-x.eu/
```

### 同期状況を取得する

```bash
curl -X POST -H "Content-Type: application/json" --data '{"jsonrpc":"2.0","method":"eth_syncing","params":[],"id":1}' https://rpc.test.pontus-x.eu/
```
