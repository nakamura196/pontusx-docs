# サブグラフ — トランザクションキャッシュ

サブグラフは [The Graph](https://thegraph.com/) の上に構築されており、ブロックチェーンからサービスの価格情報と購入履歴を抽出し、それらを加工したうえで、GraphQL から素直に問い合わせられる形式で保存する役割を担います。

:::info
サブグラフは、アクセストークンとトランザクションに関するデータをブロックチェーンから直接取得します。ただし、サービス提供物に紐づくメタデータを復号したり配信したりする機能は持ちません。この役割は 2 つの別コンポーネントが担います。メタデータの配信を担うメタデータキャッシュ「Aquarius」と、メタデータの復号を担うアクセスコントローラー「Provider」です。
:::

:::warning
サブグラフへのクエリでは、トークンアドレスなどのパラメータを小文字で指定してください。これはクエリを正しく処理するために不可欠です。
:::
