# Pontus-X ネットワークガイド

本ガイドでは Pontus-X の各ネットワークを概観します。Pontus-X ネットワークは、プライバシー、スケーラビリティ、運用効率のために Oasis のアーキテクチャを活用しています。

## ネットワークの概要

### Pontus-X テストネット
Pontus-X テストネットは、開発ネットで十分に開発・検証された完成済みのユースケースを稼働させるためのネットワークです。完成したプロジェクトを収容し、実世界への適用に先立つ最終検証に必要な安定性と信頼性を提供します。

**テストネットのポータル設定と主要コンポーネント：**
- **チェーン ID：** 32457
- **RPC URL**: https://rpc.test.pontus-x.eu/
- **ブロックエクスプローラー URL：** [Pontus-X Explorer Testnet](https://explorer.pontus-x.eu/pontusx/test)
- **Provider URL：** `https://provider.test.pontus-x.eu`
- **Aquarius URL：** `https://aquarius.pontus-x.eu`
- **サブグラフ URL：** `https://subgraph.test.pontus-x.eu`

### Pontus-X 開発ネット
開発ネットは、新しい機能・アルゴリズム・データセットが最初に投入され、検証される動的な開発環境です。

**開発ネットのポータル設定と主要コンポーネント：**
- **チェーン ID：** 32456
- **RPC URL**: https://rpc.dev.pontus-x.eu/
- **ブロックエクスプローラー URL：** [Pontus-X Explorer Devnet](https://explorer.pontus-x.eu/pontusx/dev)
- **Provider URL：** `https://provider.dev.pontus-x.eu`
- **Aquarius URL：** `https://aquarius.pontus-x.eu`
- **サブグラフ URL：** `https://subgraph.dev.pontus-x.eu`

## ネットワーク操作

### 最新ブロックを取得する
```bash
curl -X POST -H "Content-Type: application/json" --data '{"jsonrpc":"2.0","method":"eth_getBlockByNumber","params":["latest", false],"id":1}' https://rpc.<network>.pontus-x.eu/
```

### 同期状況を取得する
```bash
curl -X POST -H "Content-Type: application/json" --data '{"jsonrpc":"2.0","method":"eth_syncing","params":[],"id":1}' https://rpc.<network>.pontus-x.eu/
```
*`<network>` は、問い合わせるネットワークに応じて `test` または `dev` に置き換えてください。*
