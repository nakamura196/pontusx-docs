# Pontus-X エコシステム参加者レジストリ

[Pontus-X エコシステム](https://www.pontus-x.eu/) の全参加者レジストリは、エコシステムを利用できるオンボーディング済み・本人確認済みの法人を記録するものです。Pontus-X エコシステムのオーケストレーターが収集した、あるいは参加者自身が公開した [Gaia-X Participant Credentials](https://docs.gaia-x.eu/ontology/development/classes/LegalPerson/) の形で提供された参加者情報を集約し、参照できるようにしています。

[Pontus-X エコシステム](https://www.pontus-x.eu/) では、参加者は主にその公開アドレスと、それに紐づく [Gaia-X Participant Credentials](https://docs.gaia-x.eu/ontology/development/classes/LegalPerson/) によって識別されます。この Pontus-X レジストリのほか、これらの情報はエコシステムのアプリケーション層でも次のように利用されます。

- [Pontus-X ポータル](https://portal.pontus-x.eu/)
- [Pontus-X ロギングサービス](https://explorer.pontus-x.eu/pontusx/test)
- [Pontus-X フォーセット](https://portal.pontus-x.eu/faucet)
- データスペースエコシステムに接続されたアプリケーション
- Pontus-X のガバナンスツール（投票）

アイデンティティやクレデンシャルが古い、あるいはアドレスがここに載っていないことに気づいた場合は、contact@delta-dao.com までご連絡いただくか、[エコシステム参加用のオンボーディング申請](https://onboarding.delta-dao.com/) をご利用ください。

## エコシステム参加者

**Pontus-X エコシステムレジストリ** のデータは、キャッシュ付き REST API を通じて基盤のスマートコントラクトから読み込まれる、動的に更新・分散された信頼の源に基づいています。その結果、複数のオンボーディングサービス事業者とオーケストレーターを備えた、Gaia-X フレームワークに基づくオープンなアイデンティティレジストリが実現し、単一の障害点・支配点が排除されています。
